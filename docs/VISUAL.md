# DEV-09 — identidade visual

Itaipu e laboratório usam fundo slate-950, painéis slate-900, texto slate-100,
texto secundário slate-300, ações emerald-800 e foco branco de 3 px.
Controles têm altura mínima de 44 px. Fonte de leitura: sans-serif do sistema;
dados técnicos podem usar monospace. Espaçamento: 4, 8, 12, 16 e 24 px.

Símbolos procedurais: C casa (telhado), D depósito (caixa), H geração hídrica
(onda), S solar (painel), E distribuição (raio), M serraria (dentes), F fonte
(árvore). São desenhos originais deste repositório, sem assets externos.
Estado aparece por palavra/símbolo: vazio, recebendo, construindo, operacional,
sem serviço. Cor complementa o texto. Escala regional reduz rótulos; seleção
sempre mostra o detalhe em painel HTML. O mapa OSM mantém atribuição própria.

Movimento vem dos ticks observados, nunca de uma simulação paralela. Redução de
movimento desliga os sinais transitórios; pausar mantém o último estado.
